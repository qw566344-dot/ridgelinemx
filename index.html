Controls

W / ↑Throttle
S / ↓Brake (hold when stopped to reverse)
A D / ← →Steer / lean
SpaceRear brake - locks the rear for slides
ShiftClutch - hold, rev, release for a burst (wheelies!)
Q / ELean back / forward (rotate in the air, shift weight on the ground)
RReset vehicle onto the track
TQuick retry (Time Trial / Practice)
CChange camera
Right mouse + dragLook around
Esc / PPause
F3FPS counter

In the air: throttle lifts the nose, rear brake (Space) drops it. Land with both wheels matching the slope for a smooth landing.
Gamepad: triggers = throttle/brake, left stick = steer/lean, A = reset, Y = camera, X = rear brake, RB = clutch.

Credits

Ridgeline MX - a browser motocross game.

Rendering: three.js (MIT licence). Everything else - physics, tracks, terrain, riders, sounds - is generated in code for this game.

Vehicle models: placeholders until you add your own .glb files (see MODELS.md).
